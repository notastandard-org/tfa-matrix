Mitigations

Mitigations are actions that reduce the effectiveness of a technique. Each entry below addresses one or more techniques in the TFA Matrix. Mitigations are a technical view; for victim-facing guidance see the What You Can Do section on the public view of each technique.

ID Mitigation Techniques Addressed
SAFE-M-0001 Anti-Stalkerware Scanning
Deploy anti-stalkerware detection tools to identify monitoring applications. Scan for apps with excessive permissions including location, microphone, camera, and message access.		 SAFE-T-0072
SAFE-M-0002 Device Access Controls
Implement strong device authentication. Disable installation from unknown sources. Maintain physical control of devices.		 SAFE-T-0072
SAFE-M-0003 Safe Device Acquisition
Obtain a separate device for sensitive communications if stalkerware is suspected. Removing stalkerware may alert the monitoring party.		 SAFE-T-0072
SAFE-M-0004 Operating System Hardening
Maintain current OS versions. Security updates frequently patch vulnerabilities exploited by stalkerware.		 SAFE-T-0072
SAFE-M-0005 Forensic Device Audit
Engage professional forensic analysis to identify monitoring software and preserve evidence.		 SAFE-T-0072
SAFE-M-0006 Bluetooth Tracker Detection
Use tracker detection applications to scan for nearby Bluetooth tracking devices. Enable platform-native unknown tracker alerts.		 SAFE-T-0073
SAFE-M-0007 Physical Vehicle Inspection
Conduct systematic inspection of vehicles for GPS tracking devices in common concealment locations.		 SAFE-T-0073
SAFE-M-0008 Belongings Audit
Inspect bags, clothing, and frequently carried items for concealed tracking devices.		 SAFE-T-0073
SAFE-M-0009 Evidence Preservation Protocol
If tracker discovered, document location and preserve for evidence before removal. Removal alerts monitoring party.		 SAFE-T-0073
SAFE-M-0010 Location Sharing Audit
Review all location sharing configurations across devices and services. Disable unauthorised sharing.		 SAFE-T-0074
SAFE-M-0011 Account Separation
Migrate to individual accounts for services previously shared. Use new credentials unknown to adversary.		 SAFE-T-0074
SAFE-M-0012 Carrier Account Review
Assess family phone plan features that expose location or usage data. Plan migration to individual account.		 SAFE-T-0074
SAFE-M-0013 Privacy Configuration Hardening
Configure maximum privacy settings on all social media platforms. Restrict visibility of posts, connections, and activity.		 SAFE-T-0075
SAFE-M-0014 Connection Audit
Review all followers and connections for adversary-controlled accounts. Remove suspicious connections.		 SAFE-T-0075
SAFE-M-0015 Information Disclosure Controls
Avoid posting real-time locations, routines, or future plans. Delay posting until after events conclude.		 SAFE-T-0075
SAFE-M-0016 Tag and Mention Restrictions
Disable or require approval for tags and mentions to prevent third-party location disclosure.		 SAFE-T-0075
SAFE-M-0017 Email Rule Audit
Check email settings for unauthorised forwarding rules and filters. Remove rules forwarding to unknown addresses.		 SAFE-T-0076
SAFE-M-0018 Linked Device Review
Review and remove unrecognised devices linked to messaging accounts.		 SAFE-T-0076
SAFE-M-0019 Encrypted Communications
Use end-to-end encrypted messaging for sensitive communications. Ensure adversary cannot access linked devices.		 SAFE-T-0076
SAFE-M-0020 Voicemail Security
Change voicemail PIN. Disable remote voicemail access where possible.		 SAFE-T-0076
SAFE-M-0021 Smart Home Account Takeover
Transfer device ownership to sole-controlled account. Factory reset devices and reconfigure with new credentials.		 SAFE-T-0077
SAFE-M-0022 Recording Device Audit
Identify all cameras, microphones, and recording-capable devices. Disable or remove devices that cannot be secured.		 SAFE-T-0077
SAFE-M-0023 Voice Assistant Hardening
Disable remote access features, drop-in capabilities, and voice purchasing. Delete stored recordings.		 SAFE-T-0077
SAFE-M-0024 Router Credential Reset
Change router admin credentials. Factory reset router if adversary configured it.		 SAFE-T-0078
SAFE-M-0025 Traffic Encryption
Use VPN to encrypt internet traffic and prevent network-level monitoring.		 SAFE-T-0078
SAFE-M-0026 Network Bypass
Use mobile data instead of home network for sensitive browsing.		 SAFE-T-0078
SAFE-M-0027 Calendar Sharing Audit
Review and remove unauthorised calendar sharing permissions across all calendar applications.		 SAFE-T-0079
SAFE-M-0028 Sensitive Appointment Isolation
Use separate calendar on adversary-unknown account for sensitive appointments.		 SAFE-T-0079
SAFE-M-0029 Medical Portal Security
Change credentials on health portals. Remove adversary as authorised contact.		 SAFE-T-0079
SAFE-M-0030 Information Compartmentalisation
Limit sensitive information shared with contacts who maintain relationship with adversary.		 SAFE-T-0080
SAFE-M-0031 Network Trust Assessment
Identify which contacts may relay information to adversary based on information leakage patterns.		 SAFE-T-0080
SAFE-M-0032 Canary Information Testing
Share unique details with specific contacts to identify information relay sources.		 SAFE-T-0080
SAFE-M-0033 Health Account Separation
Unlink health and fitness accounts from shared or adversary-known accounts. Create new accounts with private credentials.		 SAFE-T-0081
SAFE-M-0034 Fitness App Privacy Settings
Disable public profiles, activity sharing, and social features on fitness platforms.		 SAFE-T-0081
SAFE-M-0035 Wearable Device Reset
Factory reset wearable devices and configure with sole-controlled account.		 SAFE-T-0081
SAFE-M-0036 Password Manager Deployment
Use password manager with strong master password. Generate unique passwords for all accounts.		 SAFE-T-0082
SAFE-M-0037 Multi-Factor Authentication
Enable MFA on all accounts using authenticator app on secure device.		 SAFE-T-0082
SAFE-M-0038 Credential Entry Security
Use privacy screens. Avoid password entry where adversary can observe.		 SAFE-T-0082
SAFE-M-0039 Post-Separation Credential Reset
Change all passwords after separation, starting with email accounts.		 SAFE-T-0082
SAFE-M-0040 Account Documentation
Document all account details including usernames, associated contacts, and creation dates for recovery purposes.		 SAFE-T-0083
SAFE-M-0041 Recovery Contact Security
Change recovery email and phone to adversary-unknown contacts.		 SAFE-T-0083
SAFE-M-0042 Platform Recovery Engagement
Contact platform support for account recovery. Many platforms have DFV-specific recovery processes.		 SAFE-T-0083
SAFE-M-0043 Multiple Recovery Methods
Configure multiple recovery options so compromise of one does not eliminate account access.		 SAFE-T-0084
SAFE-M-0044 Security Question Hardening
Use fictitious answers to security questions that adversary cannot guess from personal knowledge.		 SAFE-T-0084
SAFE-M-0045 Recovery Email Security
Secure recovery email account with strong unique credentials and MFA.		 SAFE-T-0084
SAFE-M-0046 Active Session Monitoring

SAFE-M-0047 Session Termination
Use 'sign out all sessions' feature after credential changes.		 SAFE-T-0085
SAFE-M-0048 Remote Management Removal
Remove device from adversary's Find My/Find My Device account.		 SAFE-T-0086
SAFE-M-0049 Account Migration
Migrate device to sole-controlled Apple ID or Google account. Factory reset if required.		 SAFE-T-0086
SAFE-M-0050 Authenticator App Security
Use authenticator app on secure device rather than SMS-based 2FA.		 SAFE-T-0087
SAFE-M-0051 SIM Security Controls
Contact carrier to add SIM lock PIN and port-out protection.		 SAFE-T-0087
SAFE-M-0052 Hardware Security Key
Use hardware security key for highest-risk accounts.		 SAFE-T-0087
SAFE-M-0053 Cloud Account Security

SAFE-M-0054 Backup Encryption
Enable encrypted backups where available.		 SAFE-T-0088
SAFE-M-0055 Shared Account Separation
